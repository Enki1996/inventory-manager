# IMS V4.28 — Reports and analytics

- Replaces Reports low-stock table with bilingual, responsive analytics cards. Overview no longer shows fixed low-stock alerts, but expiry warnings remain. Warehouse Statements and their monthly-requirement thresholds remain unchanged.
- Date filters use inclusive Baghdad calendar dates, up to ten years; default is current month. Optional branch, book, item, movement category, and source/destination filters. The API queries the entire matching ledger (not the older 500-movement cache). Non-admin reports are restricted to the account's branch; missing branch assignments are denied.
- Counts are distinct shipment IDs within each group, not sums of unlike units. Transfers overlap incoming/outgoing summary counts. Multi-branch shipments can appear in multiple branch groups. Original lines actively reversed at the end of the selected period are excluded from operational counts; corrections remain separately visible. Details/export retain recorded and undone lines and their status.
- Stock candles use signed movement ledger, including Undo and Redo, with the current physical balance as anchor. Any unlogged baseline is disclosed. Incoming price candles use recorded receipt line prices. Chart intervals follow selected range; no price candle for periods without observations.
- Estimated stock valuation uses current stored lot costs, reconstructed from signed movement changes; missing prices excluded. Expiry profile is explicitly a current snapshot. These two and stock/price candles do not apply movement-type/source filters because those would distort balances and prices.
- Click chart segments or bars to drill down to transaction lines; detailed list paginated. XLSX export includes all filtered recorded transaction lines, with status and price in fils. Print/Save PDF uses the browser print dialog and full filtered transaction detail table.
- All chart rendering is local SVG/CSS. The four previously bundled fonts and Railway configuration remain intact. `openpyxl` is added for server-generated Excel downloads. Schema stays V10. No migration or database replacement is needed.
- Tests: `python test_v428_analytics.py` runs on an isolated temporary database and covers stock, partial reversal, report reconstruction, valuation, Excel generation, access restriction, invalid dates and previous recovery behavior. JavaScript syntax checked with Node. Full visual/browser print verification was blocked by the local browser environment; verify on Railway.
